# فحص سلسلة التحويلات

يتتبع تحويلات عنوانك ويعرض كل واحد منها: أكثر من تحويل قبل الصفحة سلسلة يجب اختصارها، والانتقال إلى HTTPS أو إلى www يجب أن يكون تحويلاً دائماً.

## ماذا تفحص

- عدد التحويلات قبل أن ترد الصفحة: أكثر من تحويل واحد سلسلة، وينصح Google بالتحويل إلى العنوان النهائي مباشرة.
- حالة كل تحويل: الانتقال إلى HTTPS، أو بين `example.com` و`www.example.com`، بتحويل مؤقت `302` أو `307` بدل التحويل الدائم `301` أو `308`.

## مثال

### خطأ

```http
HTTP/1.1 302 Found
Location: https://www.example.com/

HTTP/1.1 301 Moved Permanently
Location: https://www.example.com/ar/

HTTP/1.1 200 OK
Content-Type: text/html; charset=utf-8
```

### صحيح

```http
HTTP/1.1 301 Moved Permanently
Location: https://www.example.com/ar/

HTTP/1.1 200 OK
Content-Type: text/html; charset=utf-8
```

## كيف تُصلح

في المثال الخاطئ ينتقل `https://example.com/` إلى `www` بتحويل مؤقت، ثم إلى `/ar/` بتحويل آخر. أرسله إلى العنوان النهائي مباشرة، بتحويل دائم. في nginx، داخل كتلة `server` للاسم `example.com`:

```nginx
location = / {
    return 301 https://www.example.com/ar/;
}
location / {
    return 301 https://www.example.com$request_uri;
}
```

- في nginx يعطي الأمر `rewrite` مع الخيار `redirect` التحويل `302`: استخدم `return 301`، أو الخيار `permanent`.
- وفي Apache (الوحدة mod_rewrite) يعطي الخيار `R` وحده التحويل `302`: اكتب `[R=301,L]`.
- واستخدم العنوان النهائي في كل مكان تتحكم فيه، في روابطك وخريطة موقعك وروابط canonical، فلا يحتاج أحد إلى التحويلات أصلاً.
- وللتحويل المؤقت استخدامات صحيحة، كالتحويل إلى لغة يختارها متصفح الزائر: فهذا الفحص لا يُفشل إلا الانتقال إلى HTTPS أو بين الاسم و`www`.

## أسئلة شائعة

### لماذا يقول الفحص إنه لا ينطبق على صفحتي؟

لأن العنوان الذي أعطيته ردّ بالصفحة نفسها، دون تحويل: فلا شيء يُفحص. جرّب العنوان الذي يكتبه زوارك، مثل `http://example.com`.

### هل التحويل الواحد مشكلة؟

لا. التحويل الواحد، كالانتقال من HTTP إلى HTTPS، ينجح؛ ويفشل الفحص من تحويلين. فزواحف Google تتبع حتى 10 تحويلات متتالية، وينصح Google بالتحويل إلى العنوان النهائي مباشرة.

### لماذا يكون الانتقال إلى HTTPS بالتحويل 301 لا 302؟

لأن `302` يقول إن الانتقال مؤقت، فيبقى العميل على العنوان القديم. ويعدّ Google التحويل الدائم إشارة إلى أن العنوان الجديد هو الأساسي (canonical)، ولا يعدّ التحويل المؤقت إشارة كهذه، فقد يبقى العنوان القديم `http://` هو ما يحتفظ به Google.

### هل تتبع الأداة التحويل بوسوم `<meta>` أو بلغة JavaScript؟

لا، فهي تتبع تحويلات HTTP وحدها: `301` و`302` و`303` و`307` و`308`.

## المنهجية

نجلب العنوان الذي تعطيه باسم `ArablyzerBot`، ونتبع تحويلات HTTP حتى 10، ونقرأ ملف robots.txt لكل موقع قبل أن نتبع تحويلاً إليه. ونحفظ عنوان كل تحويل وحالته بالترتيب، وعنوان الصفحة التي تنتهي إليها. تفشل السلسلة من تحويلين قبل صفحة ترد بحالة 2xx. ويفشل كل تحويل `302` أو `307` لا يغيّر إلا البروتوكول من `http:` إلى `https:`، أو لا يغيّر إلا الاسم بين الاسم و`www.`، أو يغيّر الاثنين، ويبقي المنفذ والمسار والاستعلام. ويعطي العنوان نفسه النتيجة نفسها في كل فحص، ما دام الخادم يرد بالشيء نفسه.
