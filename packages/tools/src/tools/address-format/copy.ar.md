# فاحص صيغة العنوان الخليجي

أعطِ عنوان صفحة وتقرأ هذه الأداة العناوين البريدية في بياناتها المنظّمة وتفحص الدولة والرمز البريدي: الدولة برمز ISO من حرفين (SA وAE وOM وKW وBH وQA)، والرمز البريدي على صورة ما يستعمله بريد الدولة وبأرقام 0–9.

## ماذا تفحص

- `addressCountry` برمز ISO من حرفين لا باسم مثل «السعودية» أو “Saudi Arabia”.
- رمز بريدي بأرقام عربية شرقية أو فارسية.
- رمز بريدي على صورة خطأ لدولته: خمسة أرقام في السعودية والكويت وثلاثة في عُمان وثلاثة أو أربعة في البحرين.
- الإمارات وقطر ليس لهما نظام رموز بريدية ولا نحكم عليهما فيه.

## مثال

### خطأ

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "متجر الواحة",
  "address": {
    "@type": "PostalAddress",
    "postalCode": "12345",
    "addressCountry": "Saudi Arabia"
  }
}
</script>
```

### صحيح

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "متجر الواحة",
  "address": {
    "@type": "PostalAddress",
    "postalCode": "12345",
    "addressCountry": "SA"
  }
}
</script>
```

## كيف تُصلح

اكتب الدولة برمز ISO والرمز البريدي بأرقام 0–9 على صورة دولته:

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "متجر الواحة",
  "address": {
    "@type": "PostalAddress",
    "postalCode": "12345",
    "addressCountry": "SA"
  }
}
</script>
```

- السعودية والكويت: 5 أرقام. عُمان: 3 أرقام. البحرين: 3 أو 4 أرقام. الإمارات وقطر: احذف `postalCode`.
- في السعودية يضيف العنوان الوطني رقماً إضافياً من 4 أرقام؛ وفي الوسم لا يدخل في `postalCode` إلا بصيغة `12345-6789`.
- أبقِ الشارع والمدينة بلغة الصفحة.
- مولّد البيانات المنظّمة يكتب هذه الحقول لك.

## أسئلة شائعة

### لماذا يجب أن تكون الدولة رمزاً؟

تطلب Google في `addressCountry` رمز ISO 3166-1 من حرفين. والاسم قد لا يُربط بالدولة.

### دولتي ليس لها رمز بريدي، فماذا أكتب؟

احذف `postalCode`. الإمارات وقطر ليس لهما نظام رموز بريدية، والرمز المختلق أسوأ من لا شيء.

### هل تتحقق الأداة أن العنوان حقيقي؟

لا. تفحص كيف كُتب العنوان لا وجوده.

## المنهجية

يقرأ الفحص كل `PostalAddress` في JSON-LD للصفحة. والدولة المعطاة كائناً لا نحكم عليها. ولدول SA وKW وOM وBH نقارن الرمز البريدي بالصورة التي يستعملها بريد كل دولة؛ ولغيرها نفحص الأرقام فقط. والصور هي التي ينشرها البريد وقد تتغير؛ أخبرنا إن تغيرت.
