# مخفّف الخط العربي

يعرض صفحتك ويجد خطوط الويب العربية فيها والنص العربي الذي تعرضه، ويقول لك كم بايتًا يزن كل ملف خط مقابل نسخة فيها الحروف المستخدمة وحدها. وتستطيع بعدها تنزيل هذه النسخة بصيغة WOFF2 ومعها قاعدة `@font-face` جاهزة بـ `unicode-range`.

## ماذا تفحص

- كل خط ويب عربي حمّلته الصفحة: حجم ملفه مقابل حجم نسخة مصنوعة للحروف التي يستخدمها نص الصفحة العربي.
- تُبقي النسخة ما تحتاجه العربية: أرقام الكتابتين وعلامات الترقيم وحرفي الوصل (ZWJ وZWNJ) وصور العرض للحروف المستخدمة وجداول التشكيل في الخط (GSUB وGPOS)، فتظل الحروف تتصل.
- يُعلَّم الخط إذا كانت نسخته أصغر منه بأكثر من النصف وبأكثر من ٥٠ كيلوبايت.

## مثال

### خطأ

```html
/* The whole font file, 140 KB, for a handful of letters. */
@font-face {
  font-family: 'Brand Arabic';
  src: url('/_shared/fonts/ibm-plex-sans-arabic-400.ttf') format('truetype');
  font-display: swap;
}
```

### صحيح

```html
/* A WOFF2 file of a size the page can carry. */
@font-face {
  font-family: 'Brand Arabic';
  src: url('/_shared/fonts/arablyzer-test-arabic.woff2') format('woff2');
  font-display: swap;
}
```

## كيف تُصلح

استخدم الملف الذي تصنعه الأداة مع القاعدة التي تعطيك إياها:

```css
@font-face {
  font-family: 'Brand Arabic';
  src: url('/fonts/brand-arabic-subset.woff2') format('woff2');
  font-weight: 400;
  font-display: swap;
  unicode-range: U+20,U+30-39,U+627-64A;
}
```

- أبقِ خطك الكامل في القائمة بعدها إن أردت أن تُرسم الحروف خارج النسخة به: `font-family: 'Brand Arabic', 'Brand Arabic Full', serif`. وبغيره ترسمها الخطوط التالية.
- إذا كانت صفحاتك تعرض نصوصًا مختلفة فاصنع النسخة من نصوصها كلها، أو من خط مقسّم إلى عدة ملفات بـ `unicode-range`.
- الملف المصنوع للنص الذي عرضته الصفحة حين عرضناها. والصفحة التي تعرض حروفًا أخرى لاحقًا (نتيجة بحث، اسم مستخدم) تحتاجها هي أيضًا.

## أسئلة شائعة

### هل النسخة المخفّفة آمنة؟ وهل يبقى الوصل في العربية؟

نعم، تُبقى جداول التشكيل: فأشكال الحرف بحسب موضعه واللامات المركّبة مثل «لا» تتكوّن منها. و`unicode-range` في القاعدة يقول للمتصفح أن يستخدم الملف للحروف التي فيه وحدها، فما سواها يرسمه الخط التالي في قائمتك.

### هل تحتفظون بالملف الذي أنزّله؟

لا. يُصنع حين تطلبه، من ملف الخط الذي تحمّله صفحتك، بحجم أقصى محدود، ويُرسل إليك ولا يُخزَّن. لا يبقى من الخط شيء بعد الرد.

### لماذا لا تعلّمون إلا ما يوفّر ٥٠ كيلوبايت والنصف؟

لأن توفيرًا أقل لا يستحق عناء إبقاء ملف ثانٍ على وفق تصميمك. هذه أرقام القاعدة، ويمكنك مع ذلك تنزيل نسخة لأي خط تعرضه الأداة.

### هل أستطيع تخفيف خط ليس لي؟

راجع رخصته أولًا. كثير من الخطوط (عائلات Google Fonts مثلًا، برخصة OFL) تسمح بذلك، وبعضها يمنع تعديل الملف. الأداة لا تفحص الرخص.

## المنهجية

نعرض الصفحة، ونقرأ ملفات الخطوط التي حمّلتها والنص العربي المكتوب بكل عائلة خط، ونصنع النسخة بمُخفِّف HarfBuzz (مكتبة `hb-subset` بصيغة WebAssembly) مع تفعيل إغلاق التخطيط، فتبقى قواعد التشكيل التي تصل إلى الحروف المستخدمة. والحجم الذي نقارن به هو حجم الملف الذي استقبله المتصفح. تجد التفاصيل في صفحة القاعدة.
