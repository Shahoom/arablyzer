# مولّد وسوم مسار التنقل

اكتب خطوات مسار الصفحة، اسماً وعنواناً في كل سطر، وخذ وسوم `BreadcrumbList`: مواضع مرقّمة 1 و2 و3 بأرقام لاتينية، وعنواناً كاملاً لكل خطوة، والخطوة الأخيرة، وهي الصفحة نفسها، بلا عنوان كما تسمح Google.

## ماذا تفحص

- المواضع أرقام من 1 بالترتيب، مكتوبة بأرقام لاتينية (`1` لا `١`).
- لكل خطوة اسم؛ ولكل خطوة غير الأخيرة عنوان كامل بـ `https://`.
- الخطوة الأخيرة تقوم بلا عنوان: هي الصفحة نفسها.
- المسار يحتاج خطوتين على الأقل، الصفحة الرئيسية والصفحة.
- الخطوة التي ينقصها اسم أو عنوانها نسبي تُترك وتُسمّى.

## مثال

### خطأ

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "BreadcrumbList",
  "itemListElement": [
    { "@type": "ListItem", "position": "١", "name": "الرئيسية", "item": "/" },
    { "@type": "ListItem", "position": 2, "item": "https://www.example.com/perfumes" },
    { "@type": "ListItem", "position": 3, "name": "عطر العود الملكي" }
  ]
}
</script>
```

### صحيح

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "BreadcrumbList",
  "itemListElement": [
    { "@type": "ListItem", "position": 1, "name": "الرئيسية", "item": "https://www.example.com/" },
    { "@type": "ListItem", "position": 2, "name": "العطور", "item": "https://www.example.com/perfumes" },
    { "@type": "ListItem", "position": 3, "name": "عطر العود الملكي" }
  ]
}
</script>
```

## كيف تُصلح

ضع الكتلة في الصفحة، بالخطوات نفسها التي يعرضها المسار المرئي:

```html
{ "@type": "ListItem", "position": 2, "name": "العطور", "item": "https://www.example.com/perfumes" }
```

- اكتب الخطوات من الصفحة الرئيسية نزولاً إلى الصفحة، كما يسير الزائر.
- استعمل الأسماء نفسها التي يعرضها المسار المرئي.
- المنتج في تصنيفين له مسار واحد: الذي جاء منه الزائر أو الرئيسي.
- وكثيراً ما تكتب المنصات وسوم المسار وحدها: تأكد قبل أن تضيف غيرها.

## أسئلة شائعة

### هل تظهر وسوم المسار في النتيجة؟

قد تعرض Google المسار بدل العنوان تحت النتيجة إن كانت الوسوم صحيحة. وهي إشارة: القرار لها.

### لماذا موضع بأرقام لاتينية؟

`position` رقم في المفردات. والرقم العربي الشرقي نص لا تقرؤه Google رقماً.

### هل يصل ما أكتبه إلى Arablyzer؟

لا. المولّد يعمل في متصفحك، ولا يغادره شيء مما تكتبه.

## المنهجية

يعمل المولّد في متصفحك. ويجري اختبار فحص `breadcrumb-schema-invalid` على ما يكتبه. وتُوحَّد العناوين بمحلّل عناوين المتصفح. ويُكتب `<` في الاسم برمز هروب لئلا ينهي اسمٌ الكتلة.
