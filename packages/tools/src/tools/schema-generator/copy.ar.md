# مولّد بيانات المنتج المنظّمة (JSON-LD)

يكتب لك كود البيانات المنظّمة لصفحة منتج بصيغة JSON-LD: المنتج وعرضه بالسعر والعملة والتوفر، بالأرقام والرموز التي يطلبها Google، ولو كتبت السعر بأرقام عربية.

## ماذا تفحص

- السعر: رقم واحد بالأرقام من 0 إلى 9 ونقطة عشرية، ولو كتبته بأرقام عربية مشرقية مثل `١٢٫٥٠٠`.
- منازل السعر العشرية بحسب العملة: ثلاث للريال العُماني والدينار الكويتي والدينار البحريني، واثنتان للريال السعودي والدرهم الإماراتي.
- العملة: رمز ISO 4217 من ثلاثة أحرف، مثل `OMR` و`SAR`، لا `ر.ع.` ولا «ريال».
- التوفر: قيمة من schema.org، مثل `https://schema.org/InStock`.
- الكود نفسه: JSON سليم، بلا فاصلة زائدة ولا علامة تنصيص ناقصة.

## مثال

### خطأ

```html
<script type="application/ld+json">
  {
    "@context": "https://schema.org",
    "@type": "Product",
    "name": "بن عربي مختص",
    "offers": {
      "@type": "Offer",
      "price": "4.500",
      "priceCurrency": "KWD",
    }
  }
</script>
```

### صحيح

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "بن عربي مختص",
  "offers": {
    "@type": "Offer",
    "price": "4.500",
    "priceCurrency": "KWD",
    "availability": "https://schema.org/InStock"
  }
}
</script>
```

## كيف تُصلح

املأ الحقول، ثم انسخ الكود وضعه في صفحة المنتج، في `<head>` أو `<body>`، كوداً واحداً لكل منتج:

```html
<head>
  <title>بن عربي مختص | متجر الواحة</title>
  <!-- الكود كما يكتبه المولّد -->
  <script type="application/ld+json">
    { "@context": "https://schema.org", "@type": "Product", "name": "بن عربي مختص" }
  </script>
</head>
```

- اجعل السعر والعملة في الكود مطابقين لما يراه الزائر في الصفحة: يطلب Google أن تطابق البيانات المنظّمة محتوى الصفحة.
- إن تغيّر السعر أو التوفر، فغيّره في الكود أيضاً.
- إن كانت منصة متجرك تكتب هذا الكود بنفسها، فأصلح إعداداتها أو قالبها بدل إضافة كود ثانٍ للمنتج نفسه.

## أسئلة شائعة

### هل يضمن الكود ظهور السعر في نتائج Google؟

لا. يجعل الكود صفحتك مؤهلة لنتائج المنتجات الغنية، لكن Google لا يضمن ظهورها، وهو من يقرر متى يعرضها.

### لماذا ثلاث منازل عشرية للريال العُماني؟

لأن الريال العُماني ألف بيسة، فمنازله العشرية ثلاث في ISO 4217، ومثله الدينار الكويتي والدينار البحريني. نكتب السعر بمنازل عملته كما تعطيها بيانات متصفحك.

### هل أكتب اسم المنتج بالعربية؟

نعم، اكتبه كما يظهر في الصفحة، فالنص العربي يُحفظ في JSON كما هو.

### هل يصل ما أكتبه إلى Arablyzer؟

لا. يعمل المولّد في متصفحك، ولا يغادره شيء مما تكتبه.

## المنهجية

يعمل المولّد في متصفحك. نقرأ السعر بعد تحويل الأرقام العربية المشرقية والفارسية والفاصلة العشرية العربية `٫`، ونرفض ما ليس رقماً واحداً، ونكتبه بعدد المنازل العشرية لعملته كما تعطيه بيانات CLDR في المتصفح، المأخوذة من ISO 4217. نتحقق من العملة في قائمة ISO 4217 التي تستعملها قاعدة `product-offer-invalid`، ونكتب الكود بـ`JSON.stringify`، فلا يخرج منه إلا JSON سليم، ونكتب كل `<` فيه `<` حتى لا يُنهي النص عنصر `<script>`.
