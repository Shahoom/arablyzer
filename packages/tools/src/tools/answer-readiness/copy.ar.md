# فاحص إجابات الأسئلة الشائعة

أعطِ عنوان صفحة وتفحص هذه الأداة أن الأسئلة والإجابات في وسوم `FAQPage` فيها موجودة في الصفحة نصاً في HTML: أن يجد الزاحف أو نتيجة البحث أو مساعد الذكاء الاصطناعي الذي يقرأ الصفحة الإجابات هناك لا في الوسوم وحدها أو في ما يرسمه سكربت بعد حين.

## ماذا تفحص

- كل سؤال في `FAQPage` للصفحة موجود في النص الظاهر منها.
- وبداية كل إجابة (أول 50 حرفاً دون المسافات والوسوم) موجودة في النص الظاهر أيضاً.
- النص في الكود وفي السكربتات لا يُعدّ من الصفحة: النص الذي يقرؤه الزائر فقط.
- الصفحة التي لا وسوم `FAQPage` فيها لا شيء يُفحص فيها هنا؛ ولا تطلب الأداة أن تكون لصفحة وسوم.

## مثال

### خطأ

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "كم يستغرق الشحن؟",
      "acceptedAnswer": { "@type": "Answer", "text": "يصل الطلب خلال يومين." }
    }
  ]
}
</script>
<details>
  <summary>كم يستغرق الشحن؟</summary>
  <p>نشحن في أقرب وقت ممكن.</p>
</details>
```

### صحيح

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "كم يستغرق الشحن؟",
      "acceptedAnswer": { "@type": "Answer", "text": "يصل الطلب خلال يومين." }
    }
  ]
}
</script>
<details>
  <summary>كم يستغرق الشحن؟</summary>
  <p>يصل الطلب خلال يومين.</p>
</details>
```

## كيف تُصلح

اجعل الإجابات نصاً في الصفحة، هو نفسه في الوسوم:

```html
<details>
  <summary>كم يستغرق الشحن؟</summary>
  <p>يصل الطلب خلال يومين.</p>
</details>
```

- اكتب كل سؤال وإجابته في HTML (لا بأس بـ `<details>` مغلق).
- اكتب الوسوم من القائمة التي ترسم الصفحة نفسها؛ ومولّد وسوم الأسئلة يفعل.
- إن كان سكربت يرسم الإجابات بعد تحميل الصفحة فضعها في HTML بدلاً من ذلك، أو ارسم الصفحة في الخادم.
- احذف من الوسوم ما لا تعرضه الصفحة.

## أسئلة شائعة

### لماذا يجب أن تكون الإجابات نصاً في HTML؟

الزاحف أو المساعد الذي لا يشغّل السكربتات لا يقرأ إلا HTML. والإجابة التي تُرسم لاحقاً ليست هناك لتُوجَد، وتطلب Google أن تصف الوسوم ما هو ظاهر.

### هل تحتاج صفحتي وسوم أسئلة؟

لا. الصفحة التي بلا وسوم لا يُحكم عليها هنا. وإن أضفتها فيجب أن تطابق الصفحة.

### إجاباتي في قائمة منسدلة. هل هي ظاهرة؟

نعم إن كان النص في HTML، مفتوحة أو مغلقة. وإن كانت القائمة تجلب النص حين تُفتح فليس في HTML.

## المنهجية

يقرأ الفحص كتل `FAQPage` في JSON-LD للصفحة ويقارن كل سؤال وبداية كل إجابة بالنص الظاهر من الصفحة بعد توحيد الحروف والمسافات وحذف الوسوم من الإجابات. ويقرأ HTML كما أرسله الخادم، فالنص الذي يضيفه سكربت لا يُرى. والبداية من 50 حرفاً اختيارنا، لنترك الإجابة الطويلة التي في آخرها رابط.
