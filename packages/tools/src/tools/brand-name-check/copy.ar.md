# فاحص اتساق اسم العلامة

يقرأ المواضع التي تسمّي فيها الصفحة علامتها: `og:site_name` وبيانات Organization وWebSite المنظّمة ونص الشعار البديل وسطر الحقوق، ويتأكد أنها تقول الاسم نفسه، بالإملاء العربي وبالحروف اللاتينية. تبني منها محركات البحث ومساعدات الذكاء الاصطناعي كياناً واحداً.

## ماذا تفحص

- أن اسم العلامة واحد في `og:site_name` و`name` في JSON-LD و`alt` الشعار وسطر الحقوق، بعد توحيد الهمزة والتاء المربوطة والألف المقصورة والتطويل والحركات.
- أن الاسم الواحد لا يُكتب بإملاءين مثل «متجر الواحة» و«متجر الواحه».
- أنه حين تسمّي الصفحة علامتها بالعربية وبالحروف اللاتينية تقرنهما البيانات المنظّمة بـ `alternateName`.

## مثال

### خطأ

```html
<meta property="og:site_name" content="متجر الواحه" />
<script type="application/ld+json">
  { "@context": "https://schema.org", "@graph": [ { "@type": "Organization", "name": "Al Waha Store", "url": "https://www.example.com/" }, { "@type": "WebSite", "name": "متجر الواحة", "url": "https://www.example.com/" } ] }
</script>
```

### صحيح

```html
<meta property="og:site_name" content="متجر الواحة" />
<script type="application/ld+json">
  { "@context": "https://schema.org", "@graph": [ { "@type": "Organization", "name": "متجر الواحة", "alternateName": ["Al Waha Store"], "url": "https://www.example.com/" }, { "@type": "WebSite", "name": "متجر الواحة", "url": "https://www.example.com/" } ] }
</script>
```

## كيف تُصلح

1. اختر إملاءً واحداً للاسم العربي وكتابة واحدة للاسم اللاتيني، واستعملهما في كل مكان: إعدادات المتجر ونص الشعار البديل وتطبيق الـ SEO والتذييل.
2. أعطِ `name` في Organization بالعربية واسمها اللاتيني في `alternateName` ليعرف محرك البحث أنهما واحد.
3. اجعل `og:site_name` هو `name` في WebSite.
4. اكتب ة وه، وى وي، وأشكال همزة الألف بالطريقة نفسها في كل موضع.
5. في سلة وزد وشوبيفاي يأتي اسم المتجر من إعدادات المتجر وتطبيق الـ SEO؛ اضبطه مرة في كل منهما وراجع نص الشعار البديل.

## أسئلة شائعة

### لماذا يهتم Google باسم العلامة؟

يبني للعلامة كياناً واحداً من الأسماء التي يجدها، ويعرضه في لوحات المعرفة وأسماء المواقع. والأسماء المختلفة تشطر الكيان أو تجعله غير مؤكد.

### هل الاسم اللاتيني خطأ والصفحة عربية؟

لا. الاسمان صحيحان. يطلب الفحص أن تقرنهما البيانات المنظّمة بـ `alternateName` ليكونا علامة واحدة.

### وإن كان اسم شركتي غير اسم متجري؟

هذا جائز. يجمع الفحص أسماء الشركة معاً (Organization وسطر الحقوق) وأسماء الموقع معاً (WebSite و`og:site_name` والشعار)، ولا يقابل أحدهما بالآخر.

### هل يقارن اسماً عربياً بحروفه اللاتينية؟

لا. ذلك يحتاج نقحرة قد تختلف. إنما يطلب أن تقرنهما.

## المنهجية

نقرأ الأسماء من `og:site_name` و`name` و`alternateName` في Organization وWebSite في JSON-LD، ونص صور الشعار البديل، وسطر الحقوق؛ ونقرأ العنوان وأول عنوان رئيسي بحثاً عن ذكر الاسم. توحَّد العربية (أشكال همزة الألف والتاء المربوطة والهاء والألف المقصورة والياء والتطويل والحركات) وتهمل اللاتينية الحالة وعلامات الترقيم والمسافات. التفاصيل في صفحة القاعدة.
