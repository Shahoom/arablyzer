# فاحص بيانات مسار التنقل المنظّمة

يقرأ بيانات BreadcrumbList في الصفحة ويتأكد أن Google يستطيع بها عرض مسار الصفحة في نتيجتها: عناصر مرقّمة 1 و2 و3 بالأرقام 0–9، لكل منها اسم وعنوان كامل، عدا العنصر الأخير.

## ماذا تفحص

- أن في المسار عناصر.
- أن `position` كل عنصر عدد صحيح من 1 مكتوب بالأرقام 0–9 لا «١».
- أن المواضع تتتابع 1 و2 و3 بالترتيب.
- أن لكل عنصر `name` ولكل عنصر ما عدا الأخير عنوان `item`، وأن العنوان كامل.

## مثال

### خطأ

```html
<script type="application/ld+json">
  {
    "@context": "https://schema.org",
    "@type": "BreadcrumbList",
    "itemListElement": [
      { "@type": "ListItem", "position": "١", "name": "الرئيسية", "item": "/" },
      { "@type": "ListItem", "position": 2, "item": "https://www.example.com/perfumes" },
      { "@type": "ListItem", "position": 3, "name": "عطر العود الملكي" }
    ]
  }
</script>
```

### صحيح

```html
<script type="application/ld+json">
  {
    "@context": "https://schema.org",
    "@type": "BreadcrumbList",
    "itemListElement": [
      { "@type": "ListItem", "position": 1, "name": "الرئيسية", "item": "https://www.example.com/" },
      { "@type": "ListItem", "position": 2, "name": "العطور", "item": "https://www.example.com/perfumes" },
      { "@type": "ListItem", "position": 3, "name": "عطر العود الملكي" }
    ]
  }
</script>
```

## كيف تُصلح

1. رقّم العناصر من الصفحة الرئيسية: 1 و2 و3 أعداداً.
2. أعطِ كل عنصر `name` وعنوان `item` كاملاً بـ `https://`؛ والأخير وحده (الصفحة نفسها) يجوز أن يترك العنوان.
3. اطبع الموضع من عدّاد في القالب لا من نص منسّق.
4. أبقِ المسار في البيانات هو المسار الذي تعرضه الصفحة.
5. راجع النتيجة في اختبار النتائج الغنية من Google؛ وفي سلة وزد وشوبيفاي يكتب القالب البيانات فحدّثه أولاً.

## أسئلة شائعة

### هل لا يزال Google يعرض مسار التنقل في النتائج؟

نعم، في نتائج كثيرة، مساراً بجانب العنوان على الجوال وسطح المكتب. هو اختيار عرض عند Google، تتيحه البيانات الصالحة ولا تضمنه.

### هل `item` مطلوب في العنصر الأخير؟

لا. العنصر الأخير هو الصفحة نفسها، ويقبله Google بلا `item`.

### هل أكتب `position` نصاً مثل "1"؟

يقبل الفحص النص من الأرقام 0–9 والعدد، ويرفض «١» وأشباهه، ولا يقرؤها Google عدداً.

### هل يفحص المسار الذي تعرضه الصفحة؟

لا، البيانات فقط. تأكد أن الاثنين يقولان الشيء نفسه.

## المنهجية

نقرأ كتل JSON-LD في HTML الصفحة وكل BreadcrumbList فيها. نقرأ لكل عنصر `position` و`name` و`item` (ويُحسب `name` و`@id` للعنصر نفسه). التفاصيل في صفحة القاعدة.
