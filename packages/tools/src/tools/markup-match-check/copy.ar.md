# فاحص مطابقة الوسوم للمحتوى

أعطِ عنوان صفحة وتبحث هذه الأداة عمّا تقوله بياناتها المنظّمة في النص الذي يقرؤه الزائر: سعر المنتج وتقييمه وأسماء مسار التنقل وهاتف النشاط. والوسوم التي تقول ما لا تعرضه الصفحة مخالفة لإرشادات Google للبيانات المنظّمة. والأرقام تُقرأ بالعربية الشرقية أو بالغربية، فيطابق السعر المكتوب بإحداهما السعر المكتوب بالأخرى.


## ماذا تفحص

- أن سعر المنتج في عرضه (أو أدنى سعر) رقم تعرضه الصفحة.
- أن التقييم الذي تعطيه الوسوم، قيمته أو عدده، في الصفحة.
- أن أسماء وسوم مسار التنقل في نص الصفحة.
- أن هاتف المؤسسة أو النشاط في الوسوم في الصفحة، بآخر ثمانية أرقام منه، مهما كانت الكتابة والمسافات.
- النص الذي يقرؤه الزائر فقط يُحسب: لا نص سكربت ولا نمط.

## مثال

### خطأ

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "عطر العود الملكي",
  "image": "https://www.example.com/royal-oud.jpg",
  "offers": { "@type": "Offer", "price": "120.00", "priceCurrency": "SAR" }
}
</script>
<p>السعر: ٩٠ ر.س</p>
```

### صحيح

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "عطر العود الملكي",
  "image": "https://www.example.com/royal-oud.jpg",
  "offers": { "@type": "Offer", "price": "120.00", "priceCurrency": "SAR" }
}
</script>
<p>السعر: ١٢٠ ر.س</p>
```

## كيف تُصلح

اجعل الصفحة والوسوم تقولان الشيء نفسه، من قيمة واحدة:

```html
<p>السعر: ١٢٠ ر.س</p>
<p>التقييم: ٤٫٥ من ٥ (١٢٨ تقييماً)</p>
```

- اكتب السعر في HTML الصفحة لا في سكربت وحده، وولّد الوسوم من القيمة نفسها.
- اعرض التقييم مع عدده، أو احذفه من الوسوم.
- اعرض مسار التنقل بالأسماء التي تعطيها الوسوم.
- اعرض رقم الهاتف نصاً، أو رابط `tel:` نصه الرقم.

## أسئلة شائعة

### سعري يرسمه سكربت بعد تحميل الصفحة. هل هذه مشكلة؟

للزاحف الذي لا يشغّل السكربتات نعم: السعر ليس في HTML الذي يقرؤه، فالوسوم تقول ما لا تعرضه الصفحة. ضع السعر في HTML أو ارسم الصفحة في الخادم.

### الصفحة تعرض السعر بالضريبة والوسوم بدونها. أيهما الصحيح؟

يجب أن يكونا الرقم نفسه. وقوائم التاجر عند Google تطلب السعر الذي سيدفعه المتسوق.

### لماذا الأرقام العربية ليست مشكلة؟

يقرأ الفحص `١٢٠` و120 رقماً واحداً، ويجب أن تستعمل الوسوم الأرقام اللاتينية كما تطلب المفردات.

## المنهجية

يقرأ الفحص البيانات المنظّمة في الصفحة (JSON-LD) والنص الظاهر من HTML. ويُقرأ كل رقم في النص بأي كتابة للأرقام، بحذف فواصله ومرة بآخر فاصل فيه علامةً عشرية، ويطابق السعرُ إن ساواه أحد القراءتين إلى المرتبة العشرية الثالثة. ولا يُحكم إلا على المنتج الذي تصف به الصفحة نفسها. ويطابق الهاتف بآخر ثمانية أرقام. ولا يشغّل سكربتات الصفحة.
