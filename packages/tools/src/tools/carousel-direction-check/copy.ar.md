# فاحص اتجاه أسهم التالي والسابق

يرسم الصفحة ويجد أزرار «التالي» و«السابق» (الشرائح والصفحات المرقّمة والخطوات) التي يتجه رمزها اتجاهاً خاطئاً للقراءة من اليمين إلى اليسار: سهم «التالي» نحو اليمين، وسهم «رجوع» نحو اليسار.

## ماذا تفحص

- الأزرار التي تقول تسميتها أو `rel` أو صنفها «التالي» («التالي»، «المزيد»، `next`) أو «السابق» («السابق»، «رجوع»، `prev`) في سياق من اليمين إلى اليسار.
- اتجاه الرمز داخلها: اسم رمز Font Awesome أو Bootstrap Icons أو Lucide أو Material، أو رمز SVG، أو حرف سهم «→» «←».
- هل الرمز معكوس بـ CSS (تحويل، أو الرمز المعاكس في اتجاه اليمين إلى اليسار).

## مثال

### خطأ

```html
<a href="/offers" class="next">التالي <span class="icon-arrow-right"></span></a>
```

### صحيح

```html
<a href="/offers" class="next">التالي <span class="icon-arrow-left"></span></a>
```

## كيف تُصلح

1. في الصفحات العربية «التالي» يتجه يساراً و«السابق» يميناً. استعمل الرمز المعاكس أو اعكسه بـ CSS (أدناه).
2. في الشرائح (Swiper وSlick وOwl) فعّل خيار اليمين إلى اليسار في المكتبة وجرّب الأسهم.
3. فضّل أسماء الرموز المنطقية (`arrow-forward` و`chevron-end`) أو CSS يقلب الرمز مع الاتجاه.
4. لا تعكس الرموز التي ليست عن الاتجاه: ساعة أو عدسة بحث أو شعار.
5. جرّب على هاتف: المس كل سهم وتأكد أنه يتحرك كما يشير.

والانعكاس في الخطوة 1 بـ CSS:

```css
[dir='rtl'] .icon-arrow-right,
[dir='rtl'] .icon-arrow-left {
  transform: scaleX(-1);
}
```

## أسئلة شائعة

### لماذا لا تقلب المتصفحات الأسهم؟

لأن الرمز صورة أو حرف؛ يقلب المتصفح التخطيط لا ما يُرسم فيه. ومكتبات الرموز والشرائح ترسم أسهمها للصفحات الإنجليزية.

### هل تُعكس كل رموز الصفحة؟

لا، الرموز التي تدل على اتجاه فقط (الأسهم والأقواس والرجوع والتقدم والرد). أما رموز أشياء العالم الحقيقي فلا تُعكس.

### شريحتي بلا تسمية نصية. هل يراها الفحص؟

ينظر في `aria-label` و`title` والنص و`rel` والصنف. والزر الذي لا كلمة كهذه فيه لا يُحكم عليه؛ أعطِ أسهمك `aria-label` وهي تحتاجه لقارئات الشاشة على كل حال.

### هل ينقر الأسهم؟

لا. يرسم الصفحة ويقرأ الرموز والأنماط. لا يُنقر شيء.

## المنهجية

نرسم الصفحة في ثلاثة متصفحات وننظر، في الأزرار المقروءة من اليمين إلى اليسار، إلى دور في تسميتها أو `rel` أو صنفها، وإلى رمز معروف الاتجاه فيها. يُذكر الزر إذا كان كل رمز فيه يتجه عكس دوره. والزر بلا رمز معروف الاتجاه، أو تسميته فيها الدوران، أو يُقرأ من اليسار إلى اليمين، لا يُحكم عليه. التفاصيل في صفحة القاعدة.
