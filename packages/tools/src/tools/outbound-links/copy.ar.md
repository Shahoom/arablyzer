# فاحص الروابط الخارجية

أعطِ عنوان صفحة وتسرد هذه الأداة المواقع التي ترتبط بها، وكم رابطاً يذهب إلى كل منها وكيف علّمتها: عادية أو `nofollow` أو `sponsored` أو `ugc`. وهي معلومة: لا تخصم شيئاً، وتُريك أين ترسل الصفحة قراءها.

## ماذا تفحص

- المواقع التي ترتبط بها الصفحة، في نتيجة واحدة: كم موقعاً وكم رابطاً، وأكبر 12 موقعاً مع روابطها وعلاماتها.
- كم من روابط كل موقع عادي و`nofollow` و`sponsored` و`ugc`.
- النطاق الفرعي لموقع الصفحة هو موقع الصفحة؛ وروابط `mailto:` و`tel:` والروابط داخل الصفحة ليست روابط إلى موقع.
- روابط HTML في الصفحة فقط: الرابط الذي يكتبه سكربت بعد التحميل لا نراه.

## مثال

### خطأ

```html
<ul>
  <li><a href="/about">من نحن</a></li>
  <li><a href="/contact">اتصل بنا</a></li>
</ul>
```

### صحيح

```html
<ul>
  <li><a href="https://www.example.org/guide">دليل التحميص</a></li>
  <li><a href="https://shop.example.net/offer" rel="sponsored nofollow">عرض الشريك</a></li>
</ul>
```

## كيف تُصلح

لا شيء يُصلح. اقرأ القائمة وعلّم كل رابط بما هو:

```html
<a href="https://www.example.org/guide">دليل التحميص</a>
<a href="https://shop.example.net/offer" rel="sponsored nofollow">عرض الشريك</a>
```

- علّم بـ `rel="sponsored"` الرابط الذي نلت عليه مالاً أو شيئاً.
- علّم بـ `rel="ugc"` الروابط التي يضيفها زوارك (التعليقات والمراجعات).
- احذف الروابط إلى مواقع لم تعد تضمنها أو بدّلها، وتأكد أن الباقي يعمل بفاحص الروابط المكسورة.
- أبقِ بقية الروابط عادية: الارتباط بمصادر جيدة يفيد القراء.

## أسئلة شائعة

### هل الروابط الخارجية سيئة لترتيبي؟

لا. الارتباط بمصادر جيدة طبيعي ويفيد القراء. وما تحذر منه Google هو بيع روابط تمرّر الترتيب، والارتباط بمواقع مزعجة.

### ما الفرق بين nofollow وsponsored وugc؟

كلها تطلب من Google ألا تمنح الرابط قيمة. `sponsored` يقول إنه مدفوع، و`ugc` يقول إن زائراً أضافه، و`nofollow` العامّ. وتعدّها Google كلها إشارات.

### هل تفحص أن الروابط تعمل؟

لا: تسردها. أما فاحص الروابط المكسورة فيطلب روابط الصفحة ويقول أيها يفشل.

## المنهجية

يقرأ الفحص روابط HTML في الصفحة التي عنوانها http أو https، ويجمعها بالموقع (الاسم والجزء المسجَّل منه، فـ `blog.example.org` و`example.org` موقع واحد)، ويعدّ رموز `rel` لكل موقع. وهو معلومة فقط، فلا يُخصم شيء. وتسمّي نتيجة واحدة أكبر 12 موقعاً بعدد الروابط.
