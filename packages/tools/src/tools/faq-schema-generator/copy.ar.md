# مولّد وسوم الأسئلة الشائعة

اكتب أسئلتك مع إجاباتها وخذ الأسئلة كما تظهر في الصفحة (`<details>` لكل سؤال) ووسوم `FAQPage` مكتوبة من الكلمات نفسها، فتصف الوسوم ما يراه الزائر. وتُهرَّب الأسئلة والإجابات في الاثنين.

## ماذا تفحص

- كل سؤال مع إجابته، من كتل يفصل بينها سطر فارغ؛ ويُحذف «س:» و«ج:» و“Q:” و“A:” من أول السطر.
- يُكتب نص الصفحة والوسوم من قائمة واحدة، فيتطابقان كلمة بكلمة، وهو ما يسأل عنه فحص `faq-schema-mismatch`.
- يُهرَّب `<` و`&` وعلامات الاقتباس في الصفحة، ولا يستطيع `</script>` في سؤال أن ينهي كتلة الوسوم.
- تُترك الكتلة التي من سطر واحد (سؤال بلا إجابة).

## مثال

### خطأ

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "كم يستغرق الشحن؟",
      "acceptedAnswer": { "@type": "Answer", "text": "يصل الطلب خلال يومين." }
    }
  ]
}
</script>
<details>
  <summary>كم يستغرق الشحن؟</summary>
  <p>نشحن في أقرب وقت ممكن.</p>
</details>
```

### صحيح

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "كم يستغرق الشحن؟",
      "acceptedAnswer": { "@type": "Answer", "text": "يصل الطلب خلال يومين." }
    }
  ]
}
</script>
<details>
  <summary>كم يستغرق الشحن؟</summary>
  <p>يصل الطلب خلال يومين.</p>
</details>
```

## كيف تُصلح

ضع النص حيث ينبغي أن تظهر الأسئلة والوسوم بجانبه، وولّدهما من جديد كلما تغيّر سؤال:

```html
<details>
  <summary>كم يستغرق الشحن؟</summary>
  <p>يصل الطلب خلال يومين.</p>
</details>
```

- اكتب أسئلة حقيقية يسألها عملاؤك بإجابات تقول لهم شيئاً؛ لا أسئلة صُنعت للكلمات المفتاحية.
- أبقِ النص ظاهراً: لا بأس بـ `<details>` مغلق، أما النص الذي يرسمه سكربت فليس في HTML الذي يقرؤه الزاحف.
- احذف من الوسوم سؤالاً تحذفه من الصفحة.
- وفي المنصات تأكد هل يكتب تطبيق وسوم الأسئلة أصلاً قبل أن تضيف غيرها.

## أسئلة شائعة

### هل تعطي وسوم الأسئلة صفحتي نتائج منسّقة؟

نادراً. تعرض Google نتائج الأسئلة الشائعة المنسّقة الآن لمواقع حكومية وصحية معروفة في الغالب. وما زالت الوسوم تقول الأسئلة والإجابات بوضوح لمن يقرأ الصفحة، لكنها لا تَعِد بنتيجة منسّقة.

### لماذا يجب أن يكون النص في الصفحة؟

تطلب Google أن تصف البيانات المنظّمة ما يراه الزائر. ووسوم محتوى مخفي أو غائب مخالفة لسياساتها.

### هل يصل ما أكتبه إلى Arablyzer؟

لا. المولّد يعمل في متصفحك، ولا يغادره شيء مما تكتبه.

## المنهجية

يعمل المولّد في متصفحك. يُكتب نص الصفحة وكتلة `FAQPage` من قائمة أسئلة واحدة، ويجري اختبار فحص `faq-schema-mismatch` على ما يكتبه فلا يجد شيئاً. ويُكتب `<` في الـ JSON برمز هروب.
