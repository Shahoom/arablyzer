# «Soft 404» في Search Console: المعنى والإصلاح

معنى رسالة «Soft 404» في تقرير فهرسة الصفحات: صفحة تقول للزائر إنها غير موجودة وترد مع ذلك بالرمز 200، وكيف تصلحها حسب حال الصفحة.

## ماذا تعني

- ردّ الخادم على الصفحة بالرمز `200`، أي أن الطلب نجح، لكن Google رأى في محتواها صفحة خطأ: رسالة تقول إن الصفحة غير موجودة، أو صفحة فارغة، أو صفحة بلا محتوى رئيسي.
- يستبعد Google هذه الصفحات من نتائج البحث.
- قد تكون الصفحة محذوفة فعلاً ويجب أن ترد بـ `404`، وقد تكون موجودة لكن Googlebot لم يرها كما يراها الزائر.

## لماذا تظهر

قد يولّد الخادم أو نظام إدارة المحتوى أو متصفح الزائر صفحة كهذه لأسباب مختلفة، يذكر Google منها:

- ملف تضمين مفقود من جهة الخادم.
- اتصال مقطوع بقاعدة البيانات.
- صفحة نتائج بحث داخلي فارغة.
- ملف JavaScript لم يُحمَّل أو مفقود.

ومن الأسباب الشائعة أيضاً:

- صفحة محذوفة يعرض الموقع بدلها قالب «الصفحة غير موجودة»، والخادم يرد معه بـ `200`.
- تحويل الروابط المحذوفة إلى الصفحة الرئيسية بدل الرد بـ `404`.
- تطبيق صفحة واحدة (SPA) يعرض صفحة الخطأ بـ JavaScript، والخادم يرد على كل رابط بـ `200`.
- موارد لا يستطيع Googlebot تحميلها، لأنها ممنوعة في robots.txt أو بطيئة أو كثيرة، فتظهر له الصفحة فارغة أو شبه فارغة.

## كيف تُصلح

الإصلاح يتبع حال الصفحة:

- حُذفت ولا بديل لها: اجعل الخادم يرد بـ `404` أو `410`. ولك أن تصمم صفحة `404` مفيدة للزائر، بشكل موقعك وروابطه، ما دام الخادم يرد معها بالرمز `404`.
- انتقلت أو لها بديل واضح: حوّلها بـ `301` إلى رابطها الجديد.
- موجودة ومحتواها سليم: افتحها في أداة فحص عنوان URL، وانظر إلى الصفحة كما عرضها Google، وأصلح ما يمنعه من رؤية المحتوى، مثل موارد ممنوعة في robots.txt أو رسالة خطأ تظهر أثناء العرض.

وفي تطبيقات الصفحة الواحدة، حيث يصعب أن يرد الخادم بالرمز المناسب، انقل الزائر من صفحة الخطأ بـ JavaScript إلى رابط يرد عليه الخادم بـ `404`، أو أضف إلى صفحة الخطأ `noindex`:

```js
if (!product.exists) {
  // لا منتج بهذا الرابط: انقل الزائر إلى رابط يرد عليه الخادم بـ 404
  window.location.href = '/not-found'
}
```

## كيف تتحقق من الإصلاح

- اطلب الرابط وانظر إلى رمز الحالة، مثلاً بالأمر `curl -I`: الصفحة المحذوفة يجب أن ترد بـ `404` أو `410`، والمنقولة بـ `301`.
- في Search Console افتح أداة فحص عنوان URL، وشغّل الاختبار المباشر، ثم اعرض الصفحة التي اختبرها لترى لقطة شاشتها كما عرضها Google، ورمز HTTP الذي تلقّاه.
- ثم اطلب من تقرير فهرسة الصفحات التحقق من الإصلاح، ليعيد Google فحص الصفحات المتأثرة.

## أسئلة شائعة

### هل أحوّل الصفحات المحذوفة إلى الصفحة الرئيسية؟

لا. يقول Google إن تحويل الزائر إلى صفحة أخرى، مثل الصفحة الرئيسية، بدل الرد بـ `404` قد يسبب مشكلة، ويسمّي هذه الصفحات Soft 404. حوّل الرابط فقط إلى بديل واضح له، واترك ما لا بديل له يرد بـ `404` أو `410`.

### لماذا يعدّ Google صفحة سليمة Soft 404؟

الأرجح أنها لم تُحمَّل كما يجب لـ Googlebot: نقصتها موارد مهمة، أو ظهرت فيها رسالة خطأ بارزة أثناء العرض. إن رأيت في لقطة الشاشة صفحة فارغة أو شبه فارغة، فابحث عن موارد ممنوعة في robots.txt، أو كثيرة، أو بطيئة، أو ترد بأخطاء من الخادم.

### هل تضر صفحات Soft 404 بالموقع؟

تُستبعد هذه الصفحات من نتائج البحث، ويقول Google إن كشف روابط كثيرة لا تريد أن يزحف إليها، ومنها صفحات Soft 404، قد يضر بالزحف إلى الموقع وفهرسته. لذلك اجعل كل صفحة غير موجودة ترد بـ `404`.
