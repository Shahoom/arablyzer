# المحتوى المختلط (mixed content)

المحتوى المختلط صفحة على HTTPS تحمّل سكربتات أو أنماطاً أو صوراً أو وسائط عبر HTTP غير المشفّر؛ تمنع المتصفحات بعضه، وتطلب الباقي عبر HTTPS.

## التعريف

- يكون في الصفحة محتوى مختلط حين تُحمَّل عبر HTTPS، لكنها تطلب بعض مواردها عبر HTTP، دون تشفير.
- تقسمه المتصفحات إلى نوعين. المحتوى القابل للترقية، أي الصور والصوت والفيديو، تطلبه عبر HTTPS بدلاً منه، ولا يُحمَّل إن لم يكن متاحاً هناك. والمحتوى القابل للمنع تمنعه: السكربتات، وملفات CSS، والإطارات، وخطوط الويب، والطلبات عبر `fetch()`، والصور التي يختارها `srcset` أو `<picture>`. وتُمنع أيضاً الصور التي على عنوان IP بدل اسم نطاق.
- والنموذج في صفحة HTTPS الذي يرسل إلى عنوان `http:` يرسل ما يُكتب فيه دون تشفير، وقد تحذّر المتصفحات قبل إرساله.

## لماذا يهم

- السكربت أو ملف CSS الممنوع يعطّل الصفحة: تتوقف وظائف فيها، أو تفقد تنسيقها.
- من يقع في طريق طلب HTTP يستطيع قراءة ما يحمله أو تغييره: السكربت المعدَّل قد يستولي على الصفحة، والصورة المعدَّلة قد تشوّهها.
- الصورة الموجودة عبر HTTP وحده تختفي حين ترقّي المتصفحات طلبها، كما يفعل Firefox منذ الإصدار 127.

## مثال

السكربت نفسه عبر HTTP وعبر HTTPS:

```html
<!-- ممنوع في صفحة HTTPS -->
<script src="http://cdn.example.com/app.js"></script>

<!-- يُحمَّل -->
<script src="https://cdn.example.com/app.js"></script>
```

الترويسة `Content-Security-Policy: upgrade-insecure-requests` تجعل المتصفح يطلب كل عنوان `http:` في الصفحة عبر HTTPS، لكن العناوين تبقى خاطئة حيث يُقرأ HTML دونها، فأصلحها أيضاً.

## أخطاء شائعة

- عناوين `http://` باقية في القالب أو في المقالات القديمة أو في قاعدة البيانات بعد نقل الموقع إلى HTTPS.
- موارد من موقع آخر لا يقدّمها عبر HTTPS: انقلها إلى موقعك، أو استبدلها.
- الاعتماد على ترقية المتصفح للصور: الصورة غير المتاحة عبر HTTPS لا تظهر.
