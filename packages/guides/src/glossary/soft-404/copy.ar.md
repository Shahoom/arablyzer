# خطأ soft 404

خطأ soft 404 صفحة تقول للزائر إنها غير موجودة أو تظهر فارغة، وخادمها يرد مع ذلك بالرمز 200، فيستبعدها Google من البحث وتعرضها Search Console خطأً.

## التعريف

- خطأ `soft 404` رابط يعرض صفحة تقول للمستخدم إن الصفحة غير موجودة، ويرد مع ذلك برمز الحالة `200` الذي يعني النجاح. وقد تكون صفحة بلا محتوى رئيسي أو صفحة فارغة.
- حين تستنتج خوارزميات Google من محتوى الصفحة أنها صفحة خطأ، تعرضها Search Console في تقرير «فهرسة الصفحات» بالحالة «Soft 404». ومن أسبابها التي يذكرها Google: انقطاع الاتصال بقاعدة البيانات، وصفحة بحث داخلي بلا نتائج، وملف JavaScript لم يُحمَّل.

## لماذا يهم

- يرى الزائر خطأ في صفحة يقول رمزها إنها تعمل، وهي تجربة سيئة كما يقول Google، والصفحة تُستبعد من البحث.
- يستمر Google في الزحف إلى صفحات soft 404، فتستهلك من ميزانية الزحف المخصصة لموقعك.

## مثال

صفحة منتج حُذف تعرض «عذراً، هذا المنتج غير موجود» وخادمها يرد بالرمز `200`:

```text
$ curl -I https://example.com/ar/products/old-oud
HTTP/2 200
```

والإصلاح حسب الحالة:

1. حُذفت ولا بديل لها: رُدّ بالرمز `404` أو `410`.
2. انتقلت أو لها بديل واضح: حوّل إليه بتحويل دائم `301`.
3. ما زالت موجودة وسليمة: افحصها بأداة فحص عنوان URL، فلعل Googlebot لم يستطع عرضها كما يجب، أو نقصتها موارد ممنوعة في robots.txt.

## أخطاء شائعة

- صفحة 404 مخصصة يرد معها الخادم بالرمز `200`: الصفحة للزائر، والرمز `404` يبقيها خارج الفهرس.
- تطبيق صفحة واحدة (SPA) يعرض «غير موجود» عبر JavaScript والخادم يرد بالرمز `200`: يقترح Google تحويلاً عبر JavaScript إلى رابط يرد بالرمز `404`، أو إضافة `noindex` إلى صفحة الخطأ.
- صفحة سليمة يراها Google فارغة أو شبه فارغة لأن مواردها ممنوعة في robots.txt أو كثيرة جداً أو بطيئة، فتُعدّ soft 404.
