# اقتطاع الخطوط (font subsetting)

اقتطاع الخط هو حفظ ملف خط لا يحوي إلا الحروف التي يستخدمها الموقع، فيُحمَّل أسرع؛ والجزء العربي الذي تنقصه حروف أو أرقام أو علامات يكسر الكلمات.

## التعريف

- الخط المقتطع يحوي جزءاً فقط من رسوم الحروف في الملف الأصلي. وأدوات الاقتطاع تأخذ قائمة حروف أو نطاقات يونيكود، وتكتب ملفاً أصغر، بصيغة WOFF2 عادة.
- ويستطيع CSS أيضاً تقسيم الخط الواحد إلى عدة ملفات، لكل منها `unicode-range` خاص به، فلا يحمّل المتصفح الملف إلا إذا استخدمت الصفحة حرفاً من نطاقه.
- و`unicode-range` يعلن فقط ما خُصص له الملف: الحروف التي تُرسم به هي ما في النطاق وفي الملف معاً.

## لماذا يهم

- النص العربي يحتاج أكثر من الحروف الأساسية: «ڤ» و«گ» في الأسماء والعلامات التجارية، والأرقام العربية الهندية، وعلامات الترقيم مثل `،` و`؟`، والحركات. والحرف الذي لا يحويه الجزء المقتطع يُرسم وسط الكلمة بخط من خطوط جهاز الزائر، بشكل وسماكة وارتفاع مختلفة.
- وتحتاج الحروف العربية بيانات اختيار أشكال الحروف (shaping) في الخط لتتصل: فمعيار الخطوط في CSS، المستوى 4، لا يعدّ الخط داعماً لحرف إلا إذا وُجدت فيه بيانات الأشكال التي تحتاجها كتابته. وأداة الاقتطاع في fontTools تُبقي افتراضياً خصائص التخطيط اللازمة لذلك.

## مثال

خط واحد في ملفين، والصفحات التي بلا نص عربي لا تحمّل الملف العربي أبداً:

```css
@font-face {
  font-family: 'Brand';
  src: url('/fonts/brand-arabic.woff2') format('woff2');
  unicode-range: U+0600-06FF;
}
@font-face {
  font-family: 'Brand';
  src: url('/fonts/brand-latin.woff2') format('woff2');
  unicode-range: U+0000-00FF;
}
```

النطاق `U+0600-06FF` هو نطاق الحروف العربية في يونيكود، وفيه الأرقام العربية الهندية وحروف الفارسية والأردية. وبأداة fontTools:

```
fonttools subset brand-arabic.ttf --unicodes="U+0600-06FF" --flavor=woff2 --output-file=brand-arabic.woff2
```

## أخطاء شائعة

- اقتطاع الخط على نص صفحة واحدة أو شعار، ثم استخدامه في الموقع كله.
- حذف الأرقام العربية الهندية أو علامات الترقيم أو الحركات، أو حروف الأسماء مثل «پ» و«چ».
- حذف خصائص التخطيط (OpenType layout features) من الخط، والحروف العربية تحتاجها لتتصل.
- إهمال الرخصة: ينصح web.dev بالتأكد من أنها تسمح بالاقتطاع وبالاستضافة الذاتية.
