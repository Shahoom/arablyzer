# أمان النقل الصارم عبر HTTP (HSTS)

ترويسة HSTS تطلب من المتصفح ألا يصل إلى الموقع إلا عبر HTTPS لمدة محددة، فلا تبدأ زياراته التالية عبر HTTP غير المشفّر.

## التعريف

- تعرّف RFC 6797 من IETF (صدرت في 2012) آلية HSTS: طريقة يعلن بها الموقع أنه لا يُزار إلا عبر اتصالات آمنة، بالترويسة `Strict-Transport-Security` في ردوده عبر HTTPS.
- التوجيه `max-age` مطلوب، وهو عدد الثواني التي يحتفظ فيها المتصفح بالسياسة، والتوجيه `includeSubDomains` اختياري، ويمدّها إلى كل النطاقات الفرعية. أما `preload` فليس من المعيار، بل تشترطه قائمة HSTS المسبقة (preload list).
- حين يحفظ المتصفح السياسة، يحوّل كل رابط `http://` إلى الموقع إلى `https://` قبل أن يرسل الطلب، ولا يتيح تجاوز خطأ في الشهادة. وهي تخص أسماء النطاقات وحدها، لا العناوين الرقمية (IP).

## لماذا يهم

- دون HSTS، الزائر الذي يكتب اسم الموقع، أو يتبع رابط `http://` قديماً، يرسل طلبه الأول عبر HTTP، ولا ينقله إلى HTTPS إلا تحويل الموقع. وعلى شبكة غير موثوقة، كنقطة Wi-Fi عامة مزيفة، يمكن اعتراض ذلك الطلب.
- مع HSTS يتخطى المتصفح HTTP مدة `max-age` بالثواني، ويعيد العد كلما رأى الترويسة.
- تبقى الزيارة الأولى، قبل أن يرى المتصفح الترويسة، مكشوفة. وقائمة HSTS المسبقة تسدّ هذه الثغرة، لأن المتصفحات تأتي وهي فيها. لكن موقع hstspreload.org ينبّه إلى أن وصول الإزالة من القائمة إلى مستخدمي Chrome يستغرق شهوراً.

## مثال

الرد على `http://example.com/` تحويل بلا الترويسة، والرد عبر HTTPS يحملها، هنا لمدة سنة ولكل النطاقات الفرعية:

```http
HTTP/1.1 301 Moved Permanently
Location: https://example.com/

HTTP/1.1 200 OK
Strict-Transport-Security: max-age=31536000; includeSubDomains
```

ويقترح hstspreload.org البدء بمدة `max-age` قصيرة، كخمس دقائق (`max-age=300`)، ثم أسبوع، ثم شهر، قبل مدة طويلة.

## أخطاء شائعة

- إرسال الترويسة عبر HTTP، أو في التحويل من HTTP: المتصفحات تتجاهلها هناك.
- إضافة `includeSubDomains` قبل أن تعمل كل النطاقات الفرعية على HTTPS: ما يُقدَّم منها عبر HTTP وحده يصبح غير متاح.
- بقاء `max-age=0` من تجربة سابقة: هذه القيمة تطلب من المتصفح أن ينسى السياسة.
- إرسالها من `example.com` وحده والروابط كلها تذهب إلى `www.example.com`: فلا يراها المتصفح أبداً، وعلى كل مضيف أن يرسلها.
- الانضمام إلى القائمة المسبقة قبل أن يعمل النطاق كله على HTTPS.
