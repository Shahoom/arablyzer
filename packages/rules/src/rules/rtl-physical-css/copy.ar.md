# CSS يحدد الجهات باليمين واليسار

## الرسائل

### physical

يحدد ملف CSS هذا الجهة باليمين أو اليسار بدل البداية والنهاية في {count} من خصائصه، وأولها معروض هنا.

## لماذا يهم

- الصفحة العربية تبدأ سطورها من اليمين. الخاصية `margin-left` تبقى على اليسار في كل اتجاه، أما `margin-inline-start` فتكون على اليمين في الصفحة العربية وعلى اليسار في الصفحة الإنجليزية.
- كثير من القوالب مكتوبة للصفحات الإنجليزية، فإذا صارت الصفحة عربية بقيت المسافات والمحاذاة والعناصر العائمة في جهتها القديمة. ومثال شائع: `ul { padding-left: 0 }` لا يزيل مسافة القائمة في الصفحة العربية، لأن المتصفح يضعها في بداية السطر، على اليمين.
- الخصائص المنطقية تجعل ملفاً واحداً يصلح للاتجاهين، بدل ملف ثانٍ للعربية يُنسى تحديثه.
- هذه القاعدة للعلم فقط، ولا تنقص من الدرجة: الخصائص المادية تصلح إذا كُتبت لهذا الاتجاه عن قصد.

## كيف تُصلح

استخدم الخصائص المنطقية، التي تتبع اتجاه الصفحة:

| بدل | استخدم |
|---|---|
| `margin-left` و`margin-right` | `margin-inline-start` و`margin-inline-end` |
| `padding-left` و`padding-right` | `padding-inline-start` و`padding-inline-end` |
| `border-left` و`border-right` | `border-inline-start` و`border-inline-end` |
| `left` و`right` | `inset-inline-start` و`inset-inline-end` |
| `text-align: left` | `text-align: start` |
| `float: left` | `float: inline-start` |

- في Tailwind CSS استخدم الأصناف المنطقية: `ms-4` و`me-4` بدل `ml-4` و`mr-4`، و`ps-4` و`pe-4` بدل `pl-4` و`pr-4`، و`start-0` و`end-0` بدل `left-0` و`right-0`، و`text-start` بدل `text-left`.
- وفي Bootstrap، استخدم الملف `bootstrap.rtl.min.css` في الصفحات العربية.
- إذا كان للموقع ملف CSS خاص بالعربية، كالملف الذي تولّده أداة RTLCSS، فالخصائص المادية فيه مقصودة. ولا نحسب الملفات التي في اسمها `rtl`.

## كيف نكشف

1. نعرض الصفحة ونقرأ ملفات CSS التي حمّلها المتصفح، وعناصر `<style>` فيها.
2. نعدّ في كل ملف الخصائص التي تحدد الجهة باليمين أو اليسار: `margin-left` و`padding-right` و`border-left` و`left` و`right` وزوايا `border-radius`، والقيمتين `left` و`right` في `float` و`clear` و`text-align`.
3. نترك القواعد المكتوبة لاتجاه أو لغة بعينها، مثل `[dir="rtl"]` و`:dir(rtl)` و`.rtl` و`:lang(ar)`، والكتل التي تحدد اتجاهها بالخاصية `direction`، والخاصيتين المتقابلتين إذا كانت قيمتهما واحدة (`left: 0; right: 0`)، والحركات في `@keyframes`، والملفات التي في اسمها `rtl`.
4. نذكر كل ملف مرة واحدة، بعدد خصائصه وأولها. وتُحسب عناصر `<style>` في الصفحة ملفاً واحداً.
5. لا نقرأ ملفاً لم نعرف حجمه قبل قراءته، ولا ملفاً أكبر من الحد.
