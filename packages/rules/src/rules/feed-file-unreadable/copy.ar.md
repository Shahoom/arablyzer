# تعذّرت قراءة ملف المنتجات

## الرسائل

### html

العنوان يعطي صفحة ويب لا ملف منتجات. أعطنا عنوان ملف الخلاصة نفسه، ملف بامتداد xml أو txt.

### empty

الملف فارغ.

### not-utf8

الملف ليس UTF-8 صالحاً. العربية المحفوظة بترميز آخر، مثل Windows-1256 أو Latin-1، تصل إلى Merchant Center حروفاً مكسورة.

### not-xml

الملف يبدأ كأنه XML لكنه ينكسر عند السطر {line}، العمود {column}.

### not-a-feed

الملف XML، لكن عنصره الجذر «{root}» وليس `rss` أو `feed` اللذين لملف منتجات.

### no-items

لا منتجات في الملف: لا `item` في ملف RSS، ولا `entry` في ملف Atom، ولا صفوف تحت الأعمدة في ملف نصي.

### no-columns

الملف نص، لكن صفّه الأول ليس قائمة بسمات المنتج: يتوقع Merchant Center أعمدة مفصولة بعلامة جدولة مثل `id` و`title` و`price`.

## لماذا يهم

- لا يعرض Google Merchant Center منتجاً لا يقرؤه: ملف يرفضه كاملاً يعني لا منتجات في نتائج Shopping والإدراجات المجانية، ولا أسعار في إعلانات التاجر الذي يستخدمها.
- الأسباب المعتادة: عنوان خاطئ (صفحة المتجر بدل الملف)، أو إضافة كتبت الملف بترميز خاطئ، أو ملف كسره حرف لم يهرّبه المصدِّر.
- أسماء المنتجات العربية ترجّح خطأ الترميز: ملف محفوظ بـ Windows-1256 أو Latin-1 يبدو سليماً في الجدول ويصل علامات استفهام.

## كيف تُصلح

1. افتح العنوان في المتصفح. ملف المنتجات يعرض XML أو نصاً مفصولاً بعلامات جدولة، لا صفحة فيها قائمة.
2. من تصدير المنصة أو إضافة الملف، اختر صيغة Google Shopping (Merchant Center) وانسخ عنوان الملف من هناك.
3. احفظ الملف أو قدّمه بترميز UTF-8، وصرّح به في XML: `<?xml version="1.0" encoding="UTF-8"?>`.
4. هرّب `&` و`<` و`>` في أسماء المنتجات والأوصاف (`&amp;` و`&lt;` و`&gt;`)، أو ضع النص داخل `<![CDATA[ … ]]>`.
5. تأكد أن في الملف منتجاً واحداً على الأقل.

```xml
<?xml version="1.0" encoding="UTF-8"?>
<rss version="2.0" xmlns:g="http://base.google.com/ns/1.0">
  <channel>
    <title>متجر الواحة</title>
    <link>https://shop.example/</link>
    <description>منتجات متجر الواحة</description>
    <item>
      <g:id>OUD-1</g:id>
      <title>عطر العود الملكي 50 مل</title>
    </item>
  </channel>
</rss>
```

## كيف نكشف

1. نجلب العنوان المعطى كما نجلب أي صفحة ونقرأ جسم الاستجابة: لا نطلب شيئاً غيره، ولا نفتح رابط منتج أو صورة في الملف.
2. الجسم الذي يبدأ بـ `<!doctype html` أو `<html` صفحة ويب. والجسم الخالي فارغ. وما لم يكن UTF-8 صالحاً نقول ذلك.
3. نقرأ XML بقارئ صارم. ملف RSS 2.0 جذره `rss` وتحته `channel` فيه عناصر `item`؛ وملف Atom جذره `feed` فيه عناصر `entry`. أي جذر غير ذلك ليس ملف منتجات.
4. ما ليس XML ولا JSON نقرؤه نصاً مفصولاً بعلامات جدولة: يسمّي صفّه الأول عمودين على الأقل، وأحدهما `id` أو `title` أو `link` أو `price` أو `description`.
5. ملف gzip يصل كما هو (خلاصة `.gz`) لا نقرؤه: يقرؤه Merchant Center ولا يقرؤه هذا الفحص، فتقول القاعدة إنها لم تستطع الفحص ولا تعدّه عيباً.
