# خطأ في صيغة JSON داخل البيانات المنظّمة (JSON-LD)

## الرسائل

### trailing-comma

كتلة JSON-LD رقم {block} فيها فاصلة قبل قوس الإغلاق في السطر {line}، وJSON لا يسمح بذلك.

### unexpected-character

كتلة JSON-LD رقم {block} تتوقف عن كونها JSON صالحاً في السطر {line}، العمود {column}، عند «{character}»، مثلاً بسبب علامة تنصيص غير مهرّبة داخل نص.

### control-character

كتلة JSON-LD رقم {block} فيها سطر جديد أو رمز تحكم داخل نص في السطر {line}؛ اكتبه `\n` أو احذفه.

### invalid-escape

كتلة JSON-LD رقم {block} فيها تهريب غير صالح بعد `\` في السطر {line}.

### unexpected-end

كتلة JSON-LD رقم {block} تنتهي قبل أن يكتمل JSON؛ ينقصها قوس أو علامة تنصيص للإغلاق.

## لماذا يهم

- يقرأ Google البيانات المنظّمة من كتل JSON-LD ليعرض النتائج المنسّقة، مثل بيانات النشاط التجاري والأسعار والتقييمات.
- إذا لم تكن الكتلة JSON صالحاً فلا يستطيع Google قراءة أي شيء منها: تُهمَل الكتلة كلها، لا السطر الخاطئ وحده. ويعرض Search Console هذه الحالة في تقرير البيانات المنظّمة غير القابلة للتحليل (Unparsable structured data).
- من الأسباب المعروفة: فاصلة زائدة بعد آخر عنصر، وعلامة تنصيص داخل اسم عربي مثل `مطعم "الأصيل"` دون تهريب، وسطر جديد داخل نص.

## كيف تُصلح

- احذف الفاصلة التي تسبق `}` أو `]`.
- هرّب علامة التنصيص داخل النص بكتابتها `\"`، أو استخدم علامتي التنصيص العربيتين «» اللتين لا تحتاجان إلى تهريب:

```json
{
  "@context": "https://schema.org",
  "@type": "Restaurant",
  "name": "مطعم \"الأصيل\" للمأكولات البحرية"
}
```

- الأفضل أن تُولَّد الكتلة بدالة ترميز JSON في لغة البرمجة، مثل `JSON.stringify` في JavaScript أو `json_encode` في PHP، بدل كتابتها كنص يدوياً.
- بعد الإصلاح اختبر الصفحة في أداة Google لاختبار النتائج المنسّقة أو في مدقق Schema.org.

## كيف نكشف

1. نجمع كل وسوم `<script type="application/ld+json">`، بأي حالة أحرف ومع أي معاملات بعد النوع، ونتجاوز الكتل الفارغة.
2. نفحص كل كتلة فحصاً صارماً حسب مواصفة JSON (RFC 8259)، ونحدد نوع الخطأ وموضعه في الصفحة بالسطر والعمود.
3. نرقّم الكتل حسب ترتيبها بين كتل JSON-LD في الصفحة، ولكل كتلة معطوبة مخالفة واحدة عند أول خطأ فيها.

هذه القاعدة تفحص الصيغة فقط؛ صحة الأنواع والخصائص حسب Schema.org فحص آخر.
