## 1. التطبيقات والحزم (§9)

| | المسؤولية |
|---|---|
| `apps/web` **جديد** | Astro 7 بصفحات ثابتة؛ Tailwind 4 بالخصائص المنطقية وحدها؛ جزر React 19 للتفاعل وحده (نموذج الفحص، وتقدّمه، وتبويبات التقرير) بمكوّنات shadcn/ui بوضع RTL؛ والباقي مكوّنات Astro بلا JavaScript. خطا IBM Plex Sans Arabic وIBM Plex Mono من Fontsource، مقسّمان ومحمّلان مسبقاً، وأيقونات Lucide. العربية على الجذر والإنجليزية على `/en` (§1) |
| `apps/api` **جديد** | Hono وZod: `POST /api/scans` (تحقق الرابط، وTurnstile، والحد، ثم الطابور)، و`GET /api/scans/:id/events` (التقدّم بـ SSE)، و`GET /api/reports/:id` |
| `apps/worker` **جديد** | يأخذ الفحص من الطابور (BullMQ على Valkey)، ويشغّل `scan()` من الـ engine بالمحرّكات الثلاثة، متصفحاً واحداً لكل عامل (§11)، ويكتب التقرير |
| `packages/plans` **جديد** | حدود الفحص المجهول، مصدر واحد للواجهة والـ API (§3). الأرقام قرار المالك |
| `packages/i18n` **جديد** | نصوص الواجهة بالعربية والإنجليزية، بمراجعة المالك كنصوص القواعد |
| `packages/seo` | تنتقل قوالبه إلى مكوّنات Astro، ويعمل فحصه الذاتي على الموقع المبني في الـ CI |
| `infra/` **جديد** | Docker Compose للتطوير والـ staging: web وapi وworker وValkey وPostgreSQL وSmokescreen، والعامل على شبكة معزولة |

**التخزين:** PostgreSQL 16 عبر Drizzle: جدول الفحوص (الرابط، والحالة، والوقت، وملخص الدرجة) والتقرير JSON كاملاً. R2
للتقارير واللقطات لاحقاً، مع حساب Cloudflare.

## 2. رحلة الفحص المجاني

1. يلصق الزائر رابطاً في الصفحة الرئيسية، ويعمل Turnstile بصمت في الغالب.
2. `POST /api/scans`: يتحقق الـ API من الرابط كما يفعل الـ CLI اليوم (http وhttps فقط، و2048 حرفاً على الأكثر، وحل DNS ورفض
   العناوين الخاصة)، ومن Turnstile، ومن الحد لكل اتصال (token bucket في Valkey)، ثم يضع الفحص في الطابور ويعيد رقمه.
3. تفتح صفحة `/r/{id}` فوراً وتعرض التقدّم عبر SSE: الجلب، وrobots.txt، وكل متصفح، والقواعد، والدرجة.
4. عند الانتهاء تعرض الصفحة نفسها التقرير بتصميم «المختبر»، و`noindex` دائماً (§6.5): رابطه يُشارك ولا يُؤرشف.
5. الحالات الصادقة كما في لوحة التصميم: الموقع حجب الفحص، وتقرير جزئي، وعنوان لا نفحصه، وحدّ الفحوص.

## 3. الأمن (§13)

- **لا حركة خارج البوابة:** يجلب العامل ويعرض عبر `egress` كما في المرحلة 1، وفي الحاويات يُضاف Smokescreen على مستوى
  الشبكة، والعامل على شبكة لا ترى إلا البوابة. قائمة المنع تشمل عنوان IP العام للخادم نفسه وشبكات Docker (§18.3.1).
- **الحدود:** Turnstile على الفحص المجهول، وحد لكل اتصال في Valkey، وحد لكل نطاق مستهدف، وطابور بأولويات.
- **النماذج** كما هي: `checkValidity()` وحدها، بلا إرسال.
- **الخصوصية (§14):** لا نخزّن ترويسات الزائر ولا كوكيزه؛ وعنوان IP لحدود المعدل وحدها ويُحذف خلال أيام.
- **الـ API:** التحقق بـ Zod، ومعرّفات فحوص عشوائية لا تُخمَّن، ورأس `X-Robots-Tag: noindex` على التقارير.

## 4. الأداء والـ SEO (§6)

- الصفحة الرئيسية وصفحات الأدوات ثابتة، وJavaScript للنموذج وحده؛ الهدف 100 في Lighthouse وCore Web Vitals «جيدة».
- `hreflang` متبادل، و`canonical`، وJSON-LD، والقالب §6.1 مفروض بالفحص الذاتي في كل PR.
- يفحص Arablyzer صفحاته بنفسه في الـ CI، ويجب أن تنجح كلها (§6.5).

## 5. المعالم

- **M2.1 الصفحة الرئيسية والفحص المجاني:** `apps/web` بنظام التصميم، والصفحة الرئيسية بالعربية والإنجليزية، و`apps/api`
  و`apps/worker` والطابور، وصفحة التقدّم والتقرير، والحالات الأربع، وDocker Compose محلياً، واختبار من أوله لآخره على صفحات
  الـ fixtures.
- **M2.2 قالب الأداة وأول الأدوات:** صفحة الأداة ودليل الأدوات، والأدوات الثلاث الحالية، والأدوات التي تكفيها القواعد الموجودة.
- **M2.3 بقية الأدوات الأربعين:** قواعد جديدة بـ fixtures ونصوص مراجَعة، كالعادة.
- **M2.4 المكتبة والمحتوى:** صفحة لكل قاعدة، و15 دليلاً في `/fix`، والمسرد، و`/bot`، والمنهجية، وخرائط الموقع، وIndexNow،
  وصور OG.
- **M2.5 staging:** النشر على بيئة تجريبية محمية بموافقة المالك، ومعايير القبول.

## 6. المخاطر

- **الإساءة عبر الفحص المجاني** (SSRF، والإغراق): البوابة والعزل وTurnstile والحدود، واختبارات SSRF تعمل على الـ API أيضاً.
- **الذاكرة على الخادم المشترك** (3.5GB، §18.3.1): عاملا متصفح على الأكثر، ووقت الانتظار يظهر للزائر.
- **مدة الفحص** حتى 120 ثانية: تقدّم حي، وتقرير جزئي صادق.
- **100 في Lighthouse مع خط عربي:** تقسيم الخط وتحميله مسبقاً، ولا JavaScript إلا في الجزر.
- **حجم مراجعة النصوص:** 40 أداة بلغتين؛ صفحات مراجعة مجمّعة كما في المرحلة 1.
